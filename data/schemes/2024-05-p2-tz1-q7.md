$$\frac{\mathrm{d}y}{\mathrm{d}x}-y=x$$  
  
recognition that an integrating factor is required (M1)  
$$e^{\int P(x)dx} = e^{\int -1dx}$$  
$$= e^{-x}$$ (A1)  
$$e^{-x} \frac{\mathrm{d}y}{\mathrm{d}x} - e^{-x} y = x e^{-x}$$  
$$e^{-x} y = \int x e^{-x} \mathrm{d}x$$  
  
attempt to integrate right hand side using integration by parts (M1)  
$$(e^{-x} y = -x e^{-x} + \int e^{-x} \mathrm{d}x)$$  
$$= -x e^{-x} - e^{-x} + c$$  
$$y = -x - 1 + c e^{-x}$$  
  
substitute initial values $y = 2$ and $x = 0$ into an integrated expression involving $c$ (M1)  
$$2 = -1 + c \Rightarrow c = 3$$  
$$y = 3 e^{-x} - x - 1$$
